# Samsun Sarraf — Canlı Kur Tabela

Canlı altın / gümüş fiyat tabelası (HTML).

## 🌐 Canlı adres

GitHub Pages açıldıktan sonra:

**https://samsunsarraf55-bit.github.io/samsun-sarraf-tabela/**

### Pages’i açmak (1 dk)

1. Repo: https://github.com/samsunsarraf55-bit/samsun-sarraf-tabela
2. **Settings** → **Pages**
3. **Source**: Deploy from a branch
4. Branch: **main** / folder: **/ (root)** → **Save**
5. 1–2 dakika sonra yukarıdaki link çalışır

## Özellikler (yayın sürümü)

- Canlı Güneş + Ahlatcı fiyatları
- Gümüş varsayılan Ahlatcı
- Makas (marj) paneli — logoya 5 dokunuş
- Şifre: `sarraf55`
- Ons fiyatları (altın / gümüş)

Tam sürüm (RADAR Pro, çoklu kaynak seçimi vb.) proje klasöründeki `samsun-sarraf-tabela.html` dosyasındadır.
